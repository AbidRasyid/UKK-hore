# Supervisor Manual

## Role overview
Supervisor monitors teller performance, reviews transaction history, verifies daily reports, and oversees reporting and journal/audit flows.

## Daily workflow
1. Log in with the supervisor account.
2. Open the dashboard and review the attendance / transaction summary as needed.
3. Check reports and transaction history for the selected date range.
4. Review teller shifts and daily reports before approval.
5. Investigate unusual withdrawals, large balances, or mismatches in daily closing numbers.

## Approval and audit responsibilities
- Confirm that daily report totals match system calculations and physical cash.
- Review transactions sorted by most recent entries first to spot the newest activity quickly.
- Investigate anomalies before approving a report.

## Important notes
- Money values are managed as decimal values in the database for consistency across deposits, withdrawals, and balances.
- Realtime updates help supervisors monitor current activity without a manual cache reset.
- Keep user-safe, professional communication in all reports and audit notes.
