# Admin Manual

## Role overview
Admin manages users, customer accounts, journals, and the technical environment for operational continuity.

## Daily workflow
1. Log in with the administrator account.
2. Review user accounts and customer data for correctness.
3. Manage account status, user privileges, and PIN-related requests.
4. Check accounting journals and account balances after transaction activity.
5. Monitor suspicious transaction patterns and maintain system consistency.

## Operational guidance
- Money values should remain stored in decimal format to prevent incorrect rounding when financial values are processed.
- Use the transaction history pages to confirm that the newest records appear first.
- When a customer balance does not reflect the latest change, verify the teller shift, transaction completion, and the realtime event status.

## Key responsibilities
- User account management
- Customer account maintenance
- Journal and report review
- PIN request handling
- Shift and daily operation oversight
